# qr2link
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

QRコードを表示し、クリップボードやカメラからQRコードをデコードするシンプルなWebアプリケーションです。

## デモ
https://code4fukui.github.io/qr2link/

## 機能
- 現在のURLまたはカスタムの値でQRコードを表示
- クリップボードやカメラからQRコードをデコード
- デコードされた値でQRコードを更新

## 要件
なし

## 使用方法
1. [デモページ](https://code4fukui.github.io/qr2link/)を開きます
2. 現在のURLを表示するQRコードが表示されます
3. QRコードを更新するには、次のことができます:
   - ページにQRコード付きの画像を貼り付けます
   - カメラアイコンをクリックしてQRコードリーダーを起動し、QRコードをスキャンします
4. ページは解読された値でQRコードを更新します

## データ / API
このプロジェクトは以下のオープンソースライブラリを使用しています:
- [qr-code-reader](https://github.com/code4fukui/qr-code-reader)
- [qr-code](https://github.com/code4fukui/qr-code)
